# Tournament Manager

A simple Python program to manage a sports tournament using the command line.

## Features

- **Add Teams:** Add teams with a unique ID and name.
- **Record Matches:** Enter match scores to automatically update team points, wins, draws, and losses.
- **View Standings:** See the current league table sorted by points and goals.
- **View Statistics:** Check the leading team, tournament summary, and teams that haven't won a game yet.
